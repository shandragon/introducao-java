# Jogo de Dominó

Em uma universidade, os alunos tem o costume de jogar alguns jogos de mesa. O dominó é um jogo de 28 peças, onde cada peça é um par (a, b) com valores de 0 a 6. Um grupo de alunos pediu a você a construção de um programa que prepare o início de uma partida de dominó. 

Faça um programa em Java que: 

- Gere todas as 28 peças, sem repetições ((2, 5 ) e (5, 2) são a mesma peça), armazenando-as em uma estrutura de dados de sua escolha; 

- Embaralhe as peças e distribua 7 para cada um dos 4 jogadores e imprima a mão de cada um; 

- Calcule e imprima a soma total dos pontos de cada mão (soma dos dois lados de todas as peças); 

- Identifique o jogador que possui a peça (6, 6) e imprima: “Jogador {X} começa a partida”. Sendo X o número do jogador 

**Exemplo de saída:**

Jogador 1: (0,3) (2,2) (1,6) (4,5) (0,0) (3,6) (2,5) | Total: 39 

Jogador 2: (1,1) (0,6) (3,4) (2,6) (5,5) (0,2) (1,4) | Total: 40 

Jogador 3: (6,6) (0,1) (2,3) (4,4) (1,5) (3,3) (0,5) | Total: 43 

Jogador 4: (0,4) (1,2) (1,3) (2,4) (3,5) (4,6) (5,6) | Total: 46 

Jogador 3 começa a partida.
